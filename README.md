# LMS-project
Learning Platform with Smart Study Planner (LMS) is a powerful educational management system that makes online learning simple, organized, and efficient.
The project is highly useful for students, teachers, and educational institutions for managing courses, study plans, quizzes, attendance, and learning resources digitally.
